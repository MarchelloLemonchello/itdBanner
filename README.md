# 🎨 ITD Banner Generator

**Версия 1.0** | [Демо на GitHub Pages](https://marchellolemonchello.github.io/itdBanner/)


Инструмент для создания и настройки баннеров профиля на сайте **itd.com**. Позволяет легко создавать, редактировать и устанавливать баннеры без необходимости использования графических редакторов.

## ✨ Особенности

- 🖼️ **Загрузка любых изображений** (JPG, PNG, GIF, WebP)
- 🔍 **Интерактивное редактирование** с изменением масштаба и позиции
- 📐 **Сохранение пропорций** при изменении размера
- 🎯 **Точное позиционирование** с помощью мыши
- 📋 **Автоматическая генерация кода** для вставки на itd.com
- 📱 **Адаптивный интерфейс**, работающий на всех устройствах
- ⚡ **Быстрая обработка** без перезагрузки страницы

## 🚀 Быстрый старт

### Онлайн использование
1. Перейдите на [itdbanner.github.io](https://marchellolemonchello.github.io/itdBanner)
2. Следуйте инструкциям ниже

### Локальная установка
```bash
# Клонируйте репозиторий
git clone https://github.com/MarchelloLemonchello/itdBanner

# Перейдите в папку проекта
cd itdbanner

# Откройте index.html в браузере
# Или используйте локальный сервер
npx serve .
```

## Полный процесс от загрузки изображения до установки баннера на [itd.com](https://итд.com)
### Шаг 1: Открытие ITD Banner Generator
### Шаг 2: Загрузка изображения
- Нажмите кнопку "Выбрать файл":
- Откроется стандартный диалог выбора файлов
- Поддерживаются форматы: JPG, PNG, GIF, WebP, BMP
- Выберите изображение:
Рекомендуемый размер: не менее 1200×800 пикселей
Чем больше исходное изображение, тем лучше качество баннера
- После выбора файла:
Изображение автоматически загрузится
Появится интерактивная область настройки
Кнопка "Create Banner" станет активной
### Шаг 3: Настройка баннера (основной этап)

- Изменение размера выделенной области

Сохранение пропорций включено автоматически!

Зажмите ЛКМ на белом квадрате в углу и тяните

- Перемещение выделенной области
Наведите курсор в центр прямоугольника

### Шаг 4: Генерация и копирование кода
- Нажмите "Create Banner":

Обработка происходит мгновенно

Появится модальное окно с результатом

- Нажмите кнопку "copy"
### Шаг 5: Установка на itd.com
- Войдите в аккаунт на itd.com

- Перейдите в профиль:
Нажмите на аватар → "Мой профиль"
Или перейдите по прямой ссылке в профиль
- Нажмите кнопку "Нарисовать баннер"
- Открытие консоли разработчика : Нажмите F12 или Ctrl + Shift + I
- Вставка и выполнение кода
- Нажмите Enter и все готово!
